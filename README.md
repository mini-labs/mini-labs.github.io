# Mini Labs

个人工具与项目的公开说明网站。

网站：https://mini-labs.github.io/

## 目录

```text
index.html           网站入口
rclone/
  index.html         Rclone Google Drive 应用说明
  privacy.html       Rclone Google Drive 隐私政策
```

后续项目各自使用独立目录，并在网站入口添加链接。

## 发布

GitHub Pages 使用 `main` 分支的根目录发布。

## Google OAuth 地址

- 应用主页：https://mini-labs.github.io/rclone/
- 隐私政策：https://mini-labs.github.io/rclone/privacy.html
- 授权网域：`mini-labs.github.io`

本仓库仅存放公开网页。客户端 JSON、密钥、令牌、Cookie 和网盘文件应保留在本机配置中。
