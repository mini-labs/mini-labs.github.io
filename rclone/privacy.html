Rclone Google Drive 隐私政策

生效日期：2026年11月5日

应用用途

本应用供所有者个人使用，通过本机运行的 rclone 访问本人明确授权的 Google Drive。

访问和使用的数据

应用访问授权账户的文件内容、文件名和目录等元数据， 用于显示目录、读取文件及执行用户要求的上传、修改、 移动和删除操作。

存储与传输

OAuth 凭据、授权令牌和文件缓存由 rclone 保存在用户设备上。 用户可以自行管理备份。文件及相关元数据通过 Google API 在用户设备与 Google 服务之间传输。 本说明网站不接收或存储网盘文件及 OAuth 凭据。

数据共享

本个人集成不会将 Google 用户数据用于广告、销售或模型训练。 所有者通过其他软件自行进行的数据备份或共享， 由所有者另行管理。

网站托管

本说明网站由 GitHub Pages 托管，未添加分析或广告脚本。 GitHub 可能为安全目的记录访问者 IP 地址， 详见 GitHub 的隐私声明。

撤销授权与清理

用户可以在 Google 账户的第三方连接设置中撤销本应用授权。 本机凭据、缓存及备份需要由用户另行清理。 撤销授权本身不会删除 Google Drive 中的文件。

联系

请使用 OAuth 同意页面显示的支持邮箱联系所有者。
